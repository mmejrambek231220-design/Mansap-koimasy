# Деректер құбыры (tools/)

Сайт барлық деректі бір JS файлынан оқиды: `window.MK_DATA`. Оны жасаудың екі жолы бар.

| Скрипт | Не жасайды | Нәтиже |
|---|---|---|
| `generate-data.js` | Синтетикалық **демо** деректер (2020–2026, ~100 000 вакансия, hh.kz құрылымына ұқсас) | `data/dataset.js` |
| `fetch-hh.js` | Ресми **hh.ru API**-нен Қазақстандағы (area=40) **нақты** вакансияларды жинайды | `data/real-vacancies.json` (қойма) + `data/dataset-real.js` |

Екі файлдың форматы бірдей, сондықтан сайт кодын өзгертудің қажеті жоқ: бетке `data/dataset.js` орнына `data/dataset-real.js` қосу жеткілікті.

Қосымша файлдар:
- `search-queries.json` — қазақша лауазым атауы → hh-тағы орысша іздеу сұранысы.
- `fixtures/hh-sample.json` — желісіз тексеруге арналған hh жауабының шағын үлгісі.

## Жазба форматы

```
[ай, өңір, сала, лауазым, компания, жалақы (мың ₸), [дағдылар], дереккөз, тәжірибе, hh сілтемесі, жалақы толтырылды]
```

Алғашқы 9 өріс — `generate-data.js`-пен бірдей. `fetch-hh.js` тағы екеуін қосады:
10-өріс — вакансияның нақты hh сілтемесі (`alternate_url`), 11-өріс — `1` болса, жалақы көрсетілмеген және лауазым медианасымен толтырылған. `meta.realUrls = true`.

## 1. Демо деректер

```bash
node tools/generate-data.js
```

`fetch-hh.js` өңірлер, салалар, дағдылар және лауазымдар тізімін осы `data/dataset.js`-тен алады (индекстер сайтпен сәйкес болуы үшін), сондықтан демо файл әрқашан болуы керек.

## 2. hh.ru API токенін алу

hh.ru API анонимді сұраныстарға енді рұқсат бермейді (`{"errors":[{"type":"forbidden"}]}`).

1. https://dev.hh.ru сайтына hh аккаунтымен кіріңіз.
2. «Мои приложения» → **жаңа қосымшаны тіркеңіз** (атауы, мысалы «Мансап Компасы», мақсаты — курстық жұмыс).
3. Қосымша мақұлданғаннан кейін оның бетінен **access token** (қосымша токені) алыңыз.
4. Токенді `HH_TOKEN` орта айнымалысына жазыңыз. Токенді кодқа немесе git-ке салмаңыз.

## 3. Іске қосу

```bash
# Linux / macOS / Git Bash
HH_TOKEN=<токен> node tools/fetch-hh.js --details

# Windows PowerShell
$env:HH_TOKEN="<токен>"; node tools/fetch-hh.js --details

# Желісіз тексеру (токен керек емес)
node tools/fetch-hh.js --mock tools/fixtures/hh-sample.json
```

Опциялар:

| Опция | Мағынасы |
|---|---|
| `--pages N` | бір лауазым үшін бет саны (әдепкі 20 × 100; hh 2000 нәтижеден тереңірек бермейді) |
| `--query T` | тек көрсетілген лауазым(дар): қазақша атауы, индексі немесе орысша сұранысы, үтірмен |
| `--details` | әр жаңа вакансия үшін `/vacancies/{id}` — `key_skills` пен сипаттама (дағдылар әлдеқайда дәл) |
| `--mock FILE` | желінің орнына fixture файлы |
| `--store`, `--out`, `--base` | қойма, нәтиже және анықтамалық файлдарының жолдары |

Сұраныстар ~4/сек жылдамдықпен жіберіледі, 429/5xx кезінде қайталанады.
Сұраныс тақырыбында `HH-User-Agent: MansapKompasy/1.0 (coursework)` жіберіледі.

## 4. Өрістерді түрлендіру

- **Өңір**: `area.name` → 8 өңірдің бірі (Алматы, Астана/Нұр-Сұлтан, Шымкент, Караганда→Қарағанды, Атырау, Актобе→Ақтөбе, Павлодар, Усть-Каменогорск→Өскемен). Басқа қалалар тасталады.
- **Тәжірибе**: `noExperience / between1And3 / between3And6 / moreThan6` → 0..3.
- **Жалақы**: `from` және `to` орташасы, мың ₸. Басқа валюталар тұрақты бағаммен аударылады: RUB ≈ 6.2 ₸, USD ≈ 510 ₸, EUR ≈ 590 ₸. `gross` (салыққа дейін/кейін) ескерілмейді.
- **Дағдылар**: `key_skills`, вакансия атауы, `snippet` және сипаттама мәтіні орысша/ағылшынша синонимдер сөздігімен (`SKILL_SYNONYMS`) салыстырылады.
- **Лауазым**: вакансияны қай іздеу сұранысы тапса, сол лауазым (алғашқысы сақталады). **Сала** — лауазымның саласы.
- **Ай**: `published_at` бойынша, 2020 ж. қаңтардан бастап.

## 5. Тарих жинау

API тек **қазір ашық** вакансияларды береді — 2020–2025 жылдардың тарихы жоқ. Сондықтан скрипт
әр іске қосылғанда жаңа вакансияларды `data/real-vacancies.json` қоймасына **қосады** (hh id бойынша қайталанбайды)
және бүкіл қоймадан `data/dataset-real.js`-ті қайта құрады. Скриптті күн сайын (мысалы cron / Windows Task Scheduler арқылы)
іске қосып, уақыт өте келе нақты уақыттық қатар жинауға болады.

## 6. Шектеулер

- Тарих жоқ: алғашқы айларда нақты деректер тек соңғы 1–2 айды қамтиды, сондықтан болжам моделі үшін демо деректер әлі де қажет. Сайт тек толық тоқсандарды есептейді.
- Бір сұраныс бойынша ең көбі 2000 вакансия; іздеу тек вакансия атауы бойынша (`search_field=name`).
- Жалақы вакансиялардың шамамен жартысында ғана көрсетіледі; қалғаны лауазым медианасымен толтырылады (11-өріс = 1).
- Дағдыларды тану сөздікке негізделген: кейбір дағдылар табылмауы немесе қате табылуы мүмкін. `--details` дәлдікті арттырады, бірақ сұраныс санын көбейтеді.
- Валюта бағамдары тұрақты; 8 өңірден тыс қалалар есепке алынбайды.
- Тек hh.kz дереккөзі (LinkedIn, Enbek.kz жиналмайды).
- hh.ru API шарттарын сақтаңыз: токенді жарияламаңыз, сұраныс жиілігін арттырмаңыз.
