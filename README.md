# Мансап Компасы

**Курстық жұмыс тақырыбы:** «Машиналық оқыту әдістерін қолдана отырып, еңбек нарығында кәсіби дағдыларға сұранысты болжау».

Мансап Компасы — Қазақстан еңбек нарығындағы вакансияларды талдап, қандай кәсіби дағдыларға сұраныс өсетінін немесе азаятынын болжайтын веб-сайт. Болжам жалпы нарық бойынша да, әр мамандық бойынша жеке де жасалады.

## Мүмкіндіктері

- **Дағдылар болжамы** (`forecast.html`) — өңір, сала, мамандық және жыл (2027–2030) бойынша ең көп өсетін және азаятын дағдылар, тренд графигі мен 80% сенім аралығы.
- **Мамандық бойынша болжам** (`professions.html`, `profession.html`) — әр мамандықта болашақта қай дағдылардың маңызы артатыны: «Болашақтың негізгі дағдысы», «Өсіп келе жатқан», «Тұрақты», «Маңызы азаюда».
- **Дағдылар каталогы** (`skills.html`, `skill.html`) — 47 дағды, әрқайсысының сұраныс тарихы, болжамы, өңірлер мен мамандықтар бойынша бөлінісі.
- **Вакансиялар** (`vacancies.html`, `vacancy.html`) — сүзгілер, беттеу, hh.kz / LinkedIn / Enbek.kz сайттарына сілтемелер.
- **Модель сапасы** — болжам соңғы 4 тоқсанға тексеріледі (backtest), MAPE қарапайым (naive) әдіспен салыстырылады.

## Болжам моделі

`js/model.js` — **Holt-тың сөндірілген трендпен экспоненциалды тегістеу** әдісі (damped trend exponential smoothing):

1. Әр дағды бойынша вакансиялар саны тоқсанға жинақталады (2020 Q1 — қазіргі тоқсан).
2. Серия `log(1 + x)` арқылы түрлендіріледі — өсу пайызбен бағаланады.
3. α, β, φ параметрлері тор бойынша іздеумен таңдалады: бір қадамдық және 4 қадамдық болжам қателерінің қосындысы минималданады.
4. Болжам таңдалған жылдың соңына дейін шығарылады, 80% интервал есептеледі (z = 1.2816).
5. Сапасы: соңғы 4 тоқсан жасырылып, модель қалғанымен оқытылады және MAPE есептеледі.


## Іске қосу

Сайт толығымен статикалық, сервер қажет емес — `index.html` файлын браузерде ашу жеткілікті. Жергілікті сервермен ашу үшін:

```bash
npx serve .
```

Демо деректерді қайта жасау:

```bash
node tools/generate-data.js
```

Деректер жинау модулі (Python 3.10+):

```bash
cd collector
pip install -r requirements.txt
python run_all.py --hh-mock fixtures/hh_sample.json
```

Толығырақ: [collector/README.md](collector/README.md), [tools/README.md](tools/README.md).

## Деректер туралы

Сайт қазір **демо деректерді** пайдаланады (2020–2026 жж., ~100 000 вакансия, 8 өңір, 8 сала, 34 мамандық, 47 дағды). Олар нақты нарықтағы трендтерге ұқсас етіп жасалған: дағдылардың экспоненциалды және логистикалық өсуі, 2020 жылғы COVID кезіндегі құлдырау, маусымдық ауытқулар. Компания атаулары ойдан шығарылған.

`collector/` модулі нақты вакансияларды жинап, SQLite базасына сақтайды. Ол әзірге сайтқа қосылмаған.
